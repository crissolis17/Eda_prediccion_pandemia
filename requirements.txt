# =============================================================================
# TROUBLESHOOTING
# =============================================================================
#
# Error: "No module named 'xgboost'"
#   → pip install xgboost
#
# Error: "No module named 'lightgbm'"
#   → pip install lightgbm
#
# Error: "Could not find a version that satisfies the requirement apache-airflow"
#   → Instalar Airflow en un ambiente virtual separado (ver OPCIÓN 3 arriba)
#
# Error: Conflictos de dependencias
#   → pip install --upgrade pip
#   → pip install -r requirements.txt --no-cache-dir
#
# Error: "Microsoft Visual C++ 14.0 is required" (Windows)
#   → Instalar Build Tools: https://visualstudio.microsoft.com/downloads/
#   → O usar wheels precompilados: pip install --only-binary :all: lightgbm
